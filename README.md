**Twin Harbours** — an original spot-the-difference game. Three hand-drawn canvas scenes (a harbour at golden hour, a clockmaker's workshop, a night market), 24 differences hidden across them, a ticking clock, hints that cost you, and a satisfying ring-and-check mark for every find. Pure static files under `game/` — no build step, no network, no image assets: every scene is painted in code.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

Hand the entry in with `MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies `game/` and `screenshots/` to the output directory and writes its `dossier.json`.
